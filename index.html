Understand any SQL query

Paste a query and get a simple explanation, a step-by-step walkthrough, a diagram of how the data flows, where every column comes from, and a review of common mistakes with fixes. Your SQL is read in this browser tab only: it is never uploaded, and nothing is saved.

Optional: add your schema

With a schema, table and column names are checked, SELECT * is expanded, joins are judged by real keys, and each column gets its documented meaning. Any file Any Schema reads works: CREATE TABLE DDL, Prisma, JSON Schema, Salesforce, or a column-list export.

Or open a sample

What you get

  • Explain: what one row of the result means, every filter and join in plain English, step by step through CTEs and subqueries.
  • Flow: a diagram of tables, CTEs and subqueries feeding the result.
  • Columns: what each returned column means and which table columns it comes from.
  • Review: mistakes that silently return wrong rows (NOT IN with NULLs, LEFT JOIN undone by WHERE, BETWEEN on timestamps, …) with ready-to-paste fixes.
  • SQL: the query neatly formatted, with problem lines marked.

Any Query is open source (MIT). Explanations come from fixed rules about SQL, column names and (if loaded) your schema, so treat them as a careful first read and check anything important.
